# AI policy

We support using AI tools, including large language models, as aids when contributing to Z-Wave JS projects. You are responsible for every contribution you submit. Maintainers are responsible for every contribution they merge and release. We hold a high standard for all contributions to our projects.

Maintainers dedicate their time and expertise to reviewing contributions. AI-generated content that you have not personally reviewed and understood wastes that time and will not be accepted.

## Autonomous agents

**We do not allow autonomous agents to contribute to Z-Wave JS projects.** We will close pull requests or issues that we believe were created autonomously. We may mark automated comments as spam. This includes contributions that bypass the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. Do not let tools post unreviewed content on your behalf. Keep responses to the minimum needed to communicate your intent. We may hide comments that we believe are unreviewed AI output.

When you open a pull request, you must be able to explain the proposed changes in your own words. This includes the pull request description and responses to questions. If you use AI to help generate a pull request summary, you must review it for technical accuracy.

**Do not use AI to generate answers to questions from maintainers.** You must understand and be able to explain your own work. You may use AI to improve grammar or clarity, but the substance of your responses must be your own.

If you include context from an AI interaction in a comment, put it in a quote block using `>`. Disclose that AI produced the quoted text. Add your own commentary about its relevance and implications. Do not share long excerpts.

## Non-native English speakers

We understand that AI can help people communicate in a language that is not their first language. You may use AI to improve the grammar or clarity of text you wrote yourself. If you use AI to translate a comment, ensure that the translation accurately reflects your intent. Consider including the original text in a details block. This shows the work behind your contribution, helps maintainers verify the translation, and keeps the conversation readable.

## Code and documentation contributions

AI can help write code and documentation. Z-Wave JS projects require a human contributor who understands all work produced with AI assistance.

You must review and understand every contribution before submitting it. You must be able to explain every code and documentation change in a pull request. We will close pull requests that appear to contain unreviewed AI output without reviewing them.

## Our use of AI

Some Z-Wave JS projects use AI tools to assist with code reviews, issue triage, reporting, and other project management tasks. These tools may leave comments on pull requests or issues. These comments can be incorrect.

Treat a comment from an AI tool like any other review comment. If you believe it is incorrect, say so. A brief explanation is enough. Maintainers always have the final say. Ask a maintainer if you are unsure.

## Enforcement

We will close contributions that do not follow this policy. Repeated violations may result in a contributor being blocked from Z-Wave JS projects. If you believe your contribution was closed in error, contact a maintainer to discuss it.

This policy is adapted from the [Home Assistant AI policy](https://developers.home-assistant.io/docs/ai_policy), published by the Open Home Foundation.
